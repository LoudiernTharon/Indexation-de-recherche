EXPLICATION DÉTAILLÉE DU TP4 - INDEXATION DE TEXTE PAR ABR
================================================================

I. ARCHITECTURE DU PROJET
--------------------------

Le projet est organisé en 3 fichiers source comme demandé :

1. tp4.h : Fichier d'en-tête
   - Déclarations des structures de données
   - Prototypes de toutes les fonctions

2. tp4.c : Implémentation des fonctions
   - Toutes les fonctions demandées dans le sujet
   - Fonctions auxiliaires pour la gestion mémoire

3. main.c : Programme principal
   - Menu interactif avec 7 options


II. STRUCTURES DE DONNÉES
--------------------------

A. Structure T_Position
   - Représente une position d'un mot dans le texte
   - Champs : numeroLigne, ordre, numeroPhrase, suivant
   - Forme une liste chaînée triée par (ligne, ordre)

B. Structure T_Noeud
   - Représente un nœud de l'arbre binaire de recherche
   - Champs : mot (char*), nbOccurences, listePositions, filsGauche, filsDroit
   - Chaque nœud stocke un mot unique (en minuscules)

C. Structure T_Index
   - Représente l'index complet
   - Champs : racine (pointeur vers T_Noeud), nbMotsDistincts, nbMotsTotal
   - Permet de suivre les statistiques globales

D. Structure Phrase (auxiliaire)
   - Utilisée pour les questions B.6 et B.7
   - Permet de reconstruire les phrases à partir de l'index
   - Champs : numeroPhrase, mots (tableau), ordres (tableau), taille, capacite


III. IMPLÉMENTATION DES FONCTIONS
----------------------------------

QUESTION B.1 : ajouterPosition()
---------------------------------
OBJECTIF : Ajouter une position dans une liste triée

ALGORITHME :
1. Créer un nouveau nœud Position
2. Si la liste est vide, retourner le nouveau nœud
3. Si la position doit être insérée en tête (ligne/ordre plus petit), l'insérer
4. Sinon, parcourir la liste jusqu'à trouver la bonne position
5. Insérer le nœud à sa place en maintenant l'ordre

COMPLEXITÉ : O(n) où n = nombre de positions dans la liste


QUESTION B.2 : ajouterOccurence()
----------------------------------
OBJECTIF : Ajouter un mot dans l'ABR ou mettre à jour ses occurrences

ALGORITHME :
1. Convertir le mot en minuscules (pour ignorer la casse)
2. Si l'arbre est vide, créer la racine avec ce mot
3. Sinon, parcourir l'arbre selon l'ordre lexicographique :
   - Si le mot existe déjà : ajouter la position, incrémenter nbOccurences
   - Sinon : créer un nouveau nœud et l'insérer comme fils gauche ou droit
4. Mettre à jour les compteurs de l'index

COMPLEXITÉ : O(h + p) où h = hauteur de l'arbre, p = nombre de positions du mot
Dans le pire cas : O(n + p) où n = nombre de mots distincts


QUESTION B.3 : indexerFichier()
--------------------------------
OBJECTIF : Lire un fichier texte et construire l'index

ALGORITHME :
1. Ouvrir le fichier en lecture
2. Parcourir caractère par caractère :
   - Si c'est une lettre : l'ajouter au mot en cours
   - Si c'est un séparateur (espace, etc.) :
     * Ajouter le mot dans l'index avec ses coordonnées
     * Incrémenter l'ordre
   - Si c'est un point : incrémenter le numéro de phrase
   - Si c'est un retour à la ligne : incrémenter le numéro de ligne
3. Fermer le fichier
4. Retourner le nombre total de mots lus

COMPLEXITÉ : O(m × (h + p)) où m = nombre de mots dans le fichier


QUESTION B.4 : afficherIndex()
-------------------------------
OBJECTIF : Afficher tous les mots par ordre alphabétique

ALGORITHME :
1. Afficher les statistiques (nbMotsDistincts, nbMotsTotal)
2. Effectuer un parcours infixe de l'ABR (récursif) :
   - Parcourir le sous-arbre gauche
   - Afficher le nœud courant avec ses positions (format : LX-MY-PZ)
   - Parcourir le sous-arbre droit

COMPLEXITÉ : O(n × p) où n = nombre de mots distincts, p = nombre moyen de positions


QUESTION B.5 : rechercherMot()
-------------------------------
OBJECTIF : Rechercher un mot dans l'index

ALGORITHME :
1. Convertir le mot cherché en minuscules
2. Parcourir l'ABR comme une recherche binaire classique :
   - Comparer avec le nœud courant
   - Si égal : retourner le nœud
   - Si inférieur : aller à gauche
   - Si supérieur : aller à droite
3. Retourner NULL si non trouvé

COMPLEXITÉ : O(h) où h = hauteur de l'arbre


QUESTION B.6 : afficherOccurencesMot()
---------------------------------------
OBJECTIF : Afficher toutes les phrases contenant un mot donné

ALGORITHME :
1. Rechercher le mot dans l'index
2. Collecter toutes les phrases de l'index (parcours complet de l'ABR)
3. Pour chaque occurrence du mot :
   - Retrouver la phrase correspondante
   - Trier les mots de la phrase par ordre
   - Afficher la phrase reconstituée
4. Libérer la mémoire des structures auxiliaires

STRUCTURES AUXILIAIRES :
- Tableau de structures Phrase pour stocker toutes les phrases
- Chaque Phrase contient les mots et leurs ordres

COMPLEXITÉ : O(n × p + k × m log m) où :
- n = nombre de mots distincts
- p = nombre moyen de positions
- k = nombre d'occurrences du mot cherché
- m = nombre moyen de mots par phrase


QUESTION B.7 : construireTexte()
---------------------------------
OBJECTIF : Reconstruire le texte complet et l'enregistrer dans un fichier

ALGORITHME :
1. Collecter toutes les phrases (parcours complet de l'ABR)
2. Trier les phrases par numéro de phrase
3. Pour chaque phrase :
   - Trier les mots par ordre
   - Mettre la première lettre en majuscule
   - Écrire dans le fichier avec des espaces entre les mots
   - Ajouter un point à la fin
4. Fermer le fichier et libérer la mémoire

COMPLEXITÉ : O(n × p + s log s + s × m log m) où :
- n = nombre de mots distincts
- p = nombre moyen de positions
- s = nombre de phrases
- m = nombre moyen de mots par phrase


IV. FONCTIONS AUXILIAIRES
--------------------------

initialiserIndex() : Initialise un index vide
Complexité : O(1)

convertirMinuscules() : Convertit une chaîne en minuscules
Complexité : O(k) où k = longueur de la chaîne

libererPositions() : Libère une liste de positions
Complexité : O(p) où p = nombre de positions

libererNoeud() : Libère récursivement un nœud et ses fils
Complexité : O(n) où n = nombre de nœuds dans le sous-arbre

libererIndex() : Libère tout l'index
Complexité : O(n) où n = nombre total de nœuds

collecterPhrasesRecursif() : Parcourt l'ABR et collecte toutes les phrases
Complexité : O(n × p) où n = nombre de mots distincts, p = nombre moyen de positions

ajouterMotPhrase() : Ajoute un mot à une phrase (avec réallocation dynamique)
Complexité : O(1) amorti


V. GESTION MÉMOIRE
-------------------

ALLOCATION DYNAMIQUE :
- Chaque T_Position est allouée dynamiquement
- Chaque T_Noeud est alloué dynamiquement
- Les chaînes de caractères (mots) sont allouées dynamiquement
- Les tableaux de phrases utilisent realloc() pour gérer la capacité

LIBÉRATION :
- libererIndex() libère récursivement tous les nœuds
- libererNoeud() libère les fils, le mot, les positions puis le nœud lui-même
- libererPositions() libère toute la liste chaînée de positions
- Le main() appelle libererIndex() avant de quitter


VI. CHOIX D'IMPLÉMENTATION
----------------------------

1. CONVERSION EN MINUSCULES
   - Tous les mots sont stockés en minuscules dans l'ABR
   - Permet de traiter "Voiture", "voiture", "VOITURE" comme identiques
   - Facilite la recherche et la comparaison

2. ORDRE LEXICOGRAPHIQUE
   - strcmp() est utilisé pour comparer les mots
   - Garantit un ordre alphabétique naturel

3. LISTE TRIÉE DE POSITIONS
   - Les positions sont triées par (ligne, ordre)
   - Insertion en O(p) mais facilite l'affichage et la reconstruction

4. STRUCTURE PHRASE AUXILIAIRE
   - Utilisée pour B.6 et B.7
   - Permet de reconstruire les phrases efficacement
   - Tableaux dynamiques avec capacité doublée si nécessaire

5. TRI PAR SÉLECTION
   - Utilisé pour trier les phrases et les mots dans les phrases
   - Simple à implémenter, suffisant pour des textes de taille raisonnable

6. PARCOURS INFIXE
   - Utilisé pour afficher les mots dans l'ordre alphabétique
   - Propriété fondamentale des ABR


VII. COMPILATION ET EXÉCUTION
-------------------------------

COMPILATION :
gcc -o tp4 main.c tp4.c -Wall -Wextra

EXÉCUTION :
./tp4

Le programme affiche un menu avec 7 options permettant de :
- Charger un fichier texte
- Voir les caractéristiques de l'index
- Afficher tous les mots indexés
- Rechercher un mot spécifique
- Afficher les phrases contenant un mot
- Reconstruire le texte original
- Quitter (avec libération de la mémoire)


VIII. EXEMPLE D'UTILISATION
----------------------------

1. Créer un fichier test.txt avec le contenu :
   "Bonjour le monde. Le monde est beau."

2. Lancer le programme et choisir l'option 1 pour charger test.txt

3. L'index contiendra :
   - beau : L1-M5-P2
   - bonjour : L1-M1-P1
   - est : L1-M4-P2
   - le : L1-M2-P1, L1-M3-P2
   - monde : L1-M3-P1, L1-M4-P2

4. Rechercher "le" affichera ses 2 occurrences

5. Afficher les occurrences de "monde" montrera les deux phrases

6. Reconstruire le texte créera un fichier identique à l'original


IX. POINTS D'ATTENTION
-----------------------

1. GESTION DES CARACTÈRES
   - Seuls les lettres et points sont pris en compte
   - Les autres caractères sont ignorés

2. FORMAT D'AFFICHAGE
   - Les positions sont affichées comme : LX-MY-PZ
   - Les phrases se terminent toujours par un point

3. RECHERCHE INSENSIBLE À LA CASSE
   - La recherche de "MONDE" trouvera "monde", "Monde", etc.

4. MÉMOIRE
   - Toute la mémoire allouée est libérée avant de quitter
   - Pas de fuites mémoire si le programme est utilisé correctement

5. ROBUSTESSE
   - Vérification de l'ouverture des fichiers
   - Gestion des index vides
   - Messages d'erreur appropriés
